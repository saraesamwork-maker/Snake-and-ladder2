# Snakes and Ladder - Breast Cancer Awareness Edition 🎗️
## لعبة السلم والثعبان - نسخة التوعية بسرطان الثدي

An interactive, educational Snakes and Ladder web game tailored for Breast Cancer Awareness campaigns, schools, universities, and health events.

### Features
- 🎗️ **Pink Ribbon Theme**: Beautiful pink and rose-gold visual styling.
- 🌐 **Bilingual Support**: Instant toggle between English and Arabic (`🌐 العربية / English`).
- 🎲 **3D Interactive Dice**: Realistic CSS 3D cube with golden rims and pips.
- ❓ **20 Curated Awareness Questions**: Multiple Choice (MCQs) and True/False questions on early detection, mammograms, healthy habits, and facts.
- 👥 **Versus Computer & Multiplayer**: 1 vs CPU or 2 to 5 local players.
- 📱 **Fully Responsive & Standalone**: Works offline on computers, tablets, and phones.
